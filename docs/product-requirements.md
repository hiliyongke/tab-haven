## 1. 问题陈述（Problem Statement）

浏览器标签页是知识工作者的事实性工作台，但原生标签栏只提供「横向排列」，不具备组织、检索与反悔能力。用户在长时间会话中会同时遇到三个具体痛点：

1. **找不到**：开了几十上百个标签后，靠肉眼横扫标签栏定位某个页面几乎不可行（`README.md:10` 提供模糊搜索正是对此的解）。
2. **不敢关**：关闭是唯一释放手段，但误关后恢复成本极高，于是用户选择「永远不关」，标签持续堆积。
3. **关了就没了**：关窗 / 崩溃 / 换机后标签集合整体丢失，且没有留档。

不解决这三个问题的代价：用户退回「开一堆标签 + 不整理」的原始状态，或转向需要账号、需要上传数据的云端标签管理器（与隐私诉求冲突）。

Tabs 的解法是把能力集中在**可逆性**上：让「关」这个动作变得可反悔（撤销栈 + 快照 + 选择性恢复），用户才敢整理。

## 2. 目标（Goals）与非目标（Non-Goals）

### 2.1 产品目标（Outcome，非 Output）

| #   | 目标                                                                         | 判定方式                                                                                                                                                  |
| --- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| G1  | **任何经本产品执行的关闭都可反悔**：关闭路径统一进撤销栈，可一键或按批次恢复 | 撤销栈深度 `undoStackLimit` 默认 10（`src/core/schema/models.ts:137`）；恢复失败条目保留在栈中可重试（`src/platform/undo/RestoreEngine.ts:141-145`）      |
| G2  | **标签集合永不因关窗而丢失**：关窗自动快照默认开启、滚动保留                 | `autoSaveSnapshots` 默认 `true`（`models.ts:145`），`maxAutoSnapshots` 默认 10（`:149`）                                                                  |
| G3  | **零信任成本**：用户无需账号即可用满核心能力，且能自行验证「零网络」         | 权限冻结 12 项 + 双向比对脚本（`scripts/privacy-check.mjs:23-36,109-121`）；关于页信任面板 12 项权限逐条说明（`src/entrypoints/about/AboutPage.tsx:392`） |
| G4  | **组织成本低于组织收益**：聚合、拖拽、搜索三条路径都能在 2–3 次交互内完成    | 搜索常驻顶部 + `⌘K` 聚焦（`App.tsx:1005`）；命令面板 `⌘P` 三组漫游（`CommandPalette.tsx:372`）                                                            |
| G5  | **核心能力永久免费**：组织 / 固定 / 归档 / 快照 / 撤销安全网永不收费         | `README.md:158-167`                                                                                                                                       |

### 2.2 非目标（产品宪法级，违反即拒绝合并）

| 非目标                                            | 原因                                                                                           |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 自有云端账号 / 自建同步 / 订阅上报                | 与「本地优先、无自有服务器」的产品宪法直接冲突（`README.md:161`；`PRIVACY.md:11`）             |

| 引入新依赖的随意性                                | 依赖精简是刻意选择，新增须说明理由并征得同意（项目规则）                                       |

## 10. 成功度量（在无遥测前提下）

产品宪法禁止埋点，因此**不设任何基于用户行为采集的指标**。可用的替代度量：

| 类别                 | 指标                                                                 | 采集方式                             |
| -------------------- | -------------------------------------------------------------------- | ------------------------------------ |
| 正确性（本地可验证） | 撤销栈回放成功率：构造 N 个关闭批次后逐个撤销，条目与分组还原一致    | 自动化测试 + 人工抽查（不落用户端）  |
| 正确性               | 快照恢复幂等性：重复恢复同一快照不产生重复标签                       | 测试断言（`missingTabsOf` 去重口径） |
| 工程健康             | 分层覆盖率棘轮不回退；`pnpm check` 全绿                              | CI / 本地门禁                        |
| 隐私合规             | `check:privacy` 零网络命中、权限与 `PRIVACY.md` 双向一致             | 门禁脚本                             |
| 商店侧（外部可观测） | 商店评分与评论中的关键词（仅限用户主动公开发布的内容，非本产品采集） | 人工定期查看                         |

**明确不做**：DAU / 留存 / 功能使用频次 / 崩溃上报 / A/B 实验。

## 12. 关键设计决策（Design Decisions）

| #   | 决策                                                         | 放弃了什么                                   | 落点                                                              |
| --- | ------------------------------------------------------------ | -------------------------------------------- | ----------------------------------------------------------------- |
| D1  | **只管当前窗口**                                             | 跨窗口统一管理（"搜索所有窗口"默认关）       | `models.ts:179`；`README.md:5`                                    |
| D2  | **撤销栈深度 10、操作记录制**                                | 无限撤销历史                                 | `models.ts:42,137`；`core/undo/UndoStack.ts`                      |
| D3  | **恢复为纯加法**（只新建缺失项）                             | 「恢复即还原成快照那一刻」的严格语义         | `snapshots.ts:209`                                                |
| D4  | **单一备份格式，版本不符即拒绝**                             | 旧备份兼容解析                               | `models.ts:348,384-395`                                           |
| D5  | **同步镜像默认关闭**                                         | 换机即用的便利性                             | `models.ts:220`；`PRIVACY.md:69`                                  |
| D6  | **URL 归一化只动 authority**（保留 query/hash）              | 更激进的去重（`?utm_source` 等归一）         | `core/url/UrlInspector.ts:57-67`                                  |
| D7  | **禁缓存在 schema 层归一化**                                 | 自由填写的灵活性                             | `models.ts:192-206`                                               |
| D8  | **拖拽键盘抓取只用 Space，排除 Enter**                       | 键盘抓取的常规约定（避免吞掉按钮激活）       | `DndRoot.tsx:37-44`                                               |
| D9  | **自动分组只建不解散**                                       | 自动清理分组的彻底性（防止破坏用户手工分组） | `AutoGrouping.ts:18-20`                                           |
| D10 | **modulePreload 全量关闭**                                   | 启动期几十至一百多毫秒                       | `wxt.config.ts:103-115`                                           |
| D11 | **自由文本不加长度上限**                                     | 严格防御性校验（避免误清空存量真实数据）     | `models.ts:21-24`                                                 |
| D12 | **核心能力永久免费，不引入自有账号/订阅**                    | 订阅收入与云端增值                           | `README.md:158-167`                                               |
| D13 | **快照恢复时查询失败「宁多建不缺建」**                       | 严格不重复（代价是缺恢复）                   | `snapshots.ts:246-251` 注释：恢复是显式用户操作，多建可由用户撤销 |
| D14 | **恢复不入撤销栈**（撤销栈只覆盖关闭），故必须前置影响面确认 | 恢复后一键回退                               | `RestoreConfirmDialog.tsx:8-12`                                   |
