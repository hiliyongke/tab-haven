## 备注：已自动化验证 vs 需手动执行

- **已自动化**（CI 可挂）：8.1–8.4 全部通过；build 产物经 `python3` 校验 action/side_panel/icons 字段正确。
- **需手动执行**（Chrome 中实测）：第 1–7 节共 50 项。建议 `pnpm dev` 加载后逐条勾选。重点高风险的手动项：
  - **1.1 / 1.7**：侧边栏仅管当前窗口；拆分视图需 Chrome 140+
  - **2.3 / 2.4**：挂起条目转正与会话绑定（依赖真实导航时序）
  - **5.1 / 5.4**：跨重启撤销持久化与豁免（依赖真实关闭/恢复时序）
  - **6.4**：Tabstead 迁移（需先装 Tabstead 制造前身数据）
