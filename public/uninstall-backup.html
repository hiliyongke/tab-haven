卸载前，请先导出一份备份

感谢你试用 Tabs。

卸载会永久删除本机的全部 Tabs 数据，包括固定空间、常驻磁贴、全部快照与归档、稍后读和撤销栈。 这些数据只存在于你自己的浏览器里——Tabs 没有服务器，因此卸载后无法为你找回。

如何保留数据

  1. 先不要确认卸载，在浏览器里打开 chrome://extensions（Edge 为 edge://extensions）。
  2. 找到 Tabs，点击「详情」→ 打开「扩展程序选项」（或右键图标选择「选项」）。
  3. 在设置页的「数据」分区点击导出备份，保存得到的 JSON 文件。
  4. 确认备份文件已保存好，再回来完成卸载。

日后重装 Tabs 后，可在同一位置导入备份恢复全部数据（导入是事务式的，失败会整体回滚）。

本页是随扩展一起打包到本地的静态页面，不含任何网络请求，也不会记录你是否卸载。

Export a backup before you uninstall

Thanks for trying Tabs.

Uninstalling permanently deletes all Tabs data on this device, including fixed folders, pinned tiles, every snapshot and archive, your read-later queue and the undo stack. This data lives only in your own browser — Tabs has no server, so nothing can be recovered after uninstalling.

How to keep your data

  1. Do not confirm the uninstall yet. Open chrome://extensions (edge://extensions on Edge).
  2. Find Tabs, open Details → Extension options (or right-click the icon and choose Options).
  3. In the Data section of the settings page, click Export backup and save the JSON file.
  4. Confirm the file is saved, then come back and finish uninstalling.

If you reinstall Tabs later, Import backup in the same place restores everything (the import is transactional — a failure rolls back completely).

This page ships inside the extension as a local static page. It makes no network requests and does not record whether you uninstalled.
