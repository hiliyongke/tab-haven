## 修复：同站点标签被拆到两个分组的碎片化 bug（用户截图报告）
- **现象**：独立的 `yehe.woa.com` 原生组（1 个标签）与 `woa.com` 站点聚合组（内含 `yehe.woa.com`/`tcb.woa.com` 子分组）并存，同一域名出现在两个分组。
- **根因**：`deriveSections` 站点聚合只作用于「未分组」标签；原生组标题是建组时的域名快照。标签跨域导航漂移、或同站点新标签以未分组打开后，两套体系各自展示同一站点 → 碎片化；autoGroupNative 开启时 `planAutoGroups` 还会为同一站点另建重复域名组。
- **修复（两层，均为纯函数决策，不动用户手动分组）**：
  1. `src/core/site/Sections.ts`：新增 `collectSiteMergeCandidates` + `buildSitePlan`（同站点归并）。归并条件：原生组所有成员同一 (注册域,子域) + 组标题 === 站点展示标签（域名命名组；自定义名如「工作」绝不归并，标题漂移组因条件 1 也不归并）+ 未分组中存在同 (注册域,子域) 标签。归并仅在站点分区已有同子域桶时吸收（不改聚合阈值与 singles 判定），站点 section 新增 `mergedGroupIds` 字段，被吸收的原生组不再单独成区。
  2. `src/core/group/AutoGrouping.ts`：`AutoGroupPlan` 新增 `absorbIntoGroupId`；`planAutoGroups` 对单一归并组分区产出「吸收计划」（同站点未分组标签并入既有组），多组混入保守跳过。
  3. `src/platform/group/AutoGroupSync.ts`：`syncAutoGroups` 执行吸收（`tabs.group({tabIds, groupId})` 移动语义，不新建组、不改标题、不计入自动组记录，解散范围不变）。
  4. `SiteGrouping.subLabel` 改为导出。
- **收敛行为**：autoGroupNative 开启 → 吸收后收敛为「每站点一个原生组」；关闭 → 稳定的归并站点分区展示。两种状态均无振荡。
- **测试**：新增 `tests/core/site/sections-merge.test.ts`（6 个归并场景 + 3 个吸收计划场景）、扩展 `tests/platform/group/auto-group-sync.test.ts`（吸收执行路径）。遵守用户规则未运行 `pnpm test`，仅做了 typecheck + eslint（均通过）。

## 修复：右键扩展图标「打开 Tabs 面板」没反应

- 修复（`background/shared.ts`）：onClicked 同步栈内直接 `sidePanel.open({ windowId: WINDOW_ID_CURRENT })`（免预查询），失败降级 lastFocusedWindow 二次尝试，所有失败走 logDegraded。Chrome <116 无 open() 也给出诊断而非静默。
- 顺带修复快捷键路径（focus-search / open-panel / locate-active 同走 openSidePanel，此前偶发没反应同因）。
